# 导演镜头提示词框架

## 1. 图像角色定义

| 角色 | 作用 | 典型画面 |
|------|------|----------|
| 图A 微距/材质 | 建立感官细节 | 特写表面、纹理、质感、光影 |
| 图D 交互/动作 | 驱动叙事 | 手部动作、人物互动、物体运动 |
| 图B 全景/空间 | 空间跨越 | 广角环境、宏大场景、全景 |
| 图C 状态/氛围 | 视觉一致 | 色调、光影、天气、情绪 |

## 2. 通用提示词公式

> 参考 [图A] 的材质细节与 [图D] 的交互动作，生成一段从感官触碰延伸至宏大记忆空间的视频，展现视野从微距物件到 [图B] 全景的空间跨越，画面状态与 [图C] 保持一致。

## 3. 镜头序列编排

推荐节奏：

1. **近景触发（图A）**：感官特写，缓慢推进。
2. **动作介入（图D）**：人物或物体进入画面，打破静止。
3. **空间展开（图B）**：相机后拉/上升， reveal 全景。
4. **情绪定调（图C）**：保持整体光影/色调，收尾。

## 4. 转场技巧

- **匹配剪辑**：同材质、同形状、同色调。
- **相机运动**：推、拉、摇、移、跟、升降。
- **时间节奏**：慢动作、加速、定格、溶解。
- **光线连贯**：从图C 提取主光源方向与色温，贯穿所有镜头。

## 6. 示例

假设脚本为“匠人磨刀，回忆涌现”：

1. **镜头1（图A）**：微距刀身纹理，缓慢推进。
2. **镜头2（图D）**：匠人手部磨刀动作。
3. **镜头3（图B）**：工坊全景，阳光从窗户洒入。
4. **镜头4（图C）**：暖黄光影，尘埃漂浮，情绪收束。
