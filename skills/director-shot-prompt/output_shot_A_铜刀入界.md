## 整体转场建议

- **匹配元素**：从图1 的铜刀青绿锈迹与木桌纹理，过渡到图2 的木质梁柱与龙身木雕，保持“旧木 + 氧化金属”的材质连续性。
- **运动方式**：单镜头 slow dolly up + slight pull back，从特写推至全景，避免硬切，保证 5s 内一气呵成。
- **光线连贯**：高窗暖光作为贯穿光源，从图1 的局部高光延伸到图2 的整道光柱，丁达尔与尘埃在 second half 中完整呈现。
- **节奏**：前半段（约 1.5s）慢、静、触觉化；后半段（约 3.5s）逐渐展开空间，从私密记忆过渡到宏大世界。
- **情绪弧线**：凉 → 熟悉 → 惊叹 → 归属。铜刀的缺口与磨亮的刀柄暗示时间磨损，为后续小远与外公羁绊埋下伏笔。
