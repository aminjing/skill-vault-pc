# 导演镜头提示词

## 触发条件

当用户满足以下任一情况时调用本 skill：

- 上传了多张已生成的图片（如角色、场景、氛围、材质等）并附上脚本/分镜描述。
- 要求“把图片转成视频提示词”“写导演镜头提示词”“让转场流畅”等。
- 需要根据参考图生成一段带镜头语言、转场衔接的视频生成 prompt。

## 镜头角色定义

参考图中通常包含以下 4 类镜头，按图中框架命名：

1. **微距/材质镜头（图 A）**：特写、纹理、表面细节、质感、光影。用于建立“感官触碰”。
2. **全景/空间镜头（图 B）**：广角、环境、空间关系、宏大场景。用于完成“空间跨越”。
3. **状态/氛围镜头（图 C）**：色彩、光影、情绪、天气、时间感。用于保持全片视觉一致性。
4. **交互/动作镜头（图 D）**：人物动作、手部互动、物体运动、镜头前的事件。用于驱动叙事。

## 工作流程

1. **识别图像**：查看用户上传的每一张图片，将其归入上述 4 类镜头之一；若图片多于 4 张，合并同类或扩展为多个镜头组。
2. **理解脚本**：把脚本拆分成 2-5 个 scene beat（叙事节拍），每个 beat 对应一种镜头。
3. **编排镜头序列**：按照“感官触发 → 动作介入 → 空间展开 → 情绪收束”的节奏排列。
   - 常用顺序：A（微距材质）→ D（交互动作）→ B（全景跨越）→ C（状态一致/情绪定调）。
   - 也可根据脚本调整，但需保证从“近/小”到“远/大”的呼吸感。
4. **生成提示词**：对每个 beat 生成一段中文视频 prompt，核心句式：

   ```
   参考 [图A] 的材质细节与 [图D] 的交互动作，生成一段从感官触碰延伸至宏大记忆空间的视频，展现视野从微距物件到 [图B] 全景的空间跨越，画面状态与 [图C] 保持一致。
   ```

5. **补充转场说明**：在相邻镜头之间写一句“转场指令”，包括：
   - 相机运动（推、拉、摇、移、升、降、跟）。
   - 匹配元素（颜色、形状、动作、光线、材质）。
   - 时间/节奏（慢镜头、加速、定格、溶解、硬切）。

## 输出格式

```markdown
# 导演镜头提示词

## 镜头序列
1. [图A] 微距材质 — 脚本 beat 1 ...
2. [图D] 交互动作 — 脚本 beat 2 ...
3. [图B] 全景跨越 — 脚本 beat 3 ...
4. [图C] 状态一致/情绪定调 — 脚本 beat 4 ...

## 提示词（按镜头）
**镜头 1：**
中文提示词：...
参考图：图A
转场到镜头2：...

**镜头 2：**
...

## 整体转场建议
...
```

## 注意事项

- 如果用户没有提供 4 类齐全的图，缺省项用文本描述补齐。
- 转场尽量使用“同色调、同材质、同动作方向”的匹配剪辑。
- 每个 prompt 中保留“参考 [图X] 的 ...”句式，以兼容主流图生视频模型的参考图输入。
