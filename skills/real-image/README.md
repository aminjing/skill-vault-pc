# Real Image

Real Image turns basic image ideas and prompts into detailed descriptions designed to create more believable and realistic images.

## What it helps with

- Realistic people and interactions
- Natural hands and physical contact
- Candid phone photos
- Products and food
- Animals
- Image edits
- Video-ready first frames

## How to use it

1. Download `SKILL.md`.
2. Add it to ChatGPT project sources/skills or another compatible AI assistant.
3. Enter a basic image idea or prompt.
4. Ask the assistant to revise it using Real Image skill.

## Help test it

Try Real Image with your own prompt and let us know what worked or what still looked artificial.

Real Image is designed and tested primarily with ChatGPT, but it may also work with other AI assistants that support custom instructions or skill files.
